# CITCO Coconut Oil — Static Site

Preview locally using a simple static server. From this folder run one of the commands:

Using Python 3:

```bash
python3 -m http.server 8000
```

Using Node (http-server):

```bash
npx http-server -c-1 . 8000
```

Then open http://localhost:8000 in your browser.

Place real assets (logo, product images, certificates) into the `assets/` folder to replace placeholders.
